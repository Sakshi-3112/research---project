# Experiment 11: Research Project Workflow Integration

## Project Title:
Student Performance Analysis

- Google Colab
- GitHub
- Mendeley

This project analyzes student marks using Python. It calculates average marks, identifies the topper, and visualizes performance using a bar graph.

## Output:

- Topper identified
- Graph displayed

## Conclusion:
This project demonstrates integration of GitHub, Colab, and Mendeley in a research workflow.
